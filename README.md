# V4L2 Raw Capture Demo
Minimalistic C program demonstrating video capture from web cameras using Linux Video 4 Linux 2 (V4L2) API via memory mapping (`mmap`).

### Build & Run
```bash
# Clone the repository
git clone [https://github.com/toxaman55-crypto/frame_capture_-demo-.git](https://github.com/toxaman55-crypto/frame_capture_-demo-.git)
cd frame_capture_-demo-

# Build the project using Makefile
make

# Run the capture utility
./capture
-_____________________________________________________________________________________
